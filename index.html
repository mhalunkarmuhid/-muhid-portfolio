01 — About

From native Android apps to AI-integrated products.

Muhid is currently pursuing a B.Tech in Computer Engineering at Anjuman-I-Islam's Kalsekar Technical Campus (AIKTC), after completing a Diploma in Computer Engineering — but the real learning has mostly happened outside the syllabus, one project at a time.

It began with Android: native Java apps built directly in Android Studio, working through the lifecycle and layout system the hard way, before web development entered the picture. An internship at Ihaan Technologies added real-world workflow — debugging, UI/UX decisions and performance optimization on an actual product, not a classroom exercise.

From there, the work broadened into full-stack (React, Node.js, Express, MongoDB) and, more recently, into AI-integrated products — figuring out where an AI feature genuinely helps a user decide something, versus where it's just a chatbot bolted onto a search bar. Technical competitions like APCOER TECHNOTHON and NEXATHON added the pressure-tested part: building fast, then defending the decisions to judges.

The approach stays the same across all of it: learn → build → test → improve. Outside of code, competitive volleyball supplies a different kind of practice — reading a situation fast and trusting a team, which shows up more in project work than it might seem.
